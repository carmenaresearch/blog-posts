# Carmena’s Overton research posts

Election analysis from [Carmena’s Overton & Electoral Research](https://carmenaresearch.com/), an independent, non-partisan US election research firm. Each post is a markdown mirror of an article on [carmenaresearch.com/blog](https://carmenaresearch.com/blog/), with its charts and data tables. The website has the canonical versions, with interactive charts.
